# Release notes, 22 Oct 2026

Everything below is on `main` (production) unless marked local. Production = `2737adc` (Deploy #84, health ok).

| Change | Notes |
|---|---|
| Attendance Register | Attendance Dashboard > Register: employees x days with codes (P, WFH, HD, CL, SL, EL, CO, H, WO, A), totals, status filter, CSV; project hours register with project breakdown. `GET /attendance-dashboard/register`. |
| Timesheet Dashboard tab hidden | Frontend only (commented out in `TimeAttendanceHubPage.jsx`); `?section=dashboard` falls back to Attendance. |
| Applicant Reject | `job_applicants.rejected_at / rejected_by / reject_reason` (migration `20261022090000_applicant_reject`), `POST /applicants/:id/reject` and `/unreject`, Rejected tab, audit log. |
| Profit on Team Capacity | `profit = monthly billing - team salary - vendor cost`, per team and in totals. |
| Exited employees cannot sign in | `hasExited` in `auth.service.js` (all memberships terminated, none working; group super admins exempt). Login 403, refresh 401. |
| Time for people who have left | Add entry / Manual attendance / OT apply pick-lists use `include_terminated` ("(exited)"); Project Timesheets overview keeps people who left in the months they worked. Leave on behalf of someone who left is still refused. |
| Live role changes | Server reads the role from the DB on every request; the app re-reads `/users/me` on focus and every 5 minutes. Deployments never rewrite custom roles (tests in `custom-roles.test.js`). |
| Group Travel meetings | Meetings of every group company, labelled and filterable by company, group-scoped. |
| Announcements for admins | Birthdays and anniversaries card on the Finance landing tab. |
| Vendor email | `NOTIFICATIONS_*` and `MS_GRAPH_*` now reach the server container; Microsoft Graph sender (`lib/email/graphMail.js`). See `docs/guides/EMAIL-SMTP-PRODUCTION.md`. |
