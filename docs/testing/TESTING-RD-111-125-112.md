## Manual

### RD-111 — Stage buttons

1. Recruiter → open a submission detail.  
2. Under **Stage**, click **Move to internal screening** → confirm.  
3. Try **Move to backout** without reason → Confirm disabled; enter reason → succeeds and locks path.  
4. Advance toward offer: add/resolve interview rounds first (RD-125) or API will reject offer if rounds pending.

### RD-125 — Interview rounds

1. On submission detail → **+ Add round** (opens **RHS drawer**, not a centered modal).  
2. Set **Interview date & time** (required) + type **Internal**, result **pass**, feedback + rating → Save.  
3. Without interview date → save blocked with validation error.  
4. Add **Client L1** with date + pending.  
5. **Edit** a round → change date/feedback/result → Save.  
6. List shows interview date on each card; round types use distinct colors.

### RD-112 — Kanban

1. Requirement detail → **Pipeline board** (or `/requirements/:id/board`).  
2. Columns = pipeline stages + backout/rejected.  
3. Cards show candidate; click opens submission.  
4. Recruiter can use **→ next stage** chips on cards (prompt for backout/reject reason).
